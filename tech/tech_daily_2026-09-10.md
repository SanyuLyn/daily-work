### [2026 AI 时代下，Flutter 和 Dart 的机遇和未来发展，AI 一体化](https://zhuanlan.zhihu.com/p/2023038328287634312)
**摘要**：文章系统梳理了 Flutter 在 AI 时代的生态位。作者认为 Flutter 已经跑通了「UI + Agent + 全栈 AI 一体化」这条路线，在各主流跨平台框架里属于 AI 工程化能力相对完整的一个：Flutter MCP 让 AI 能理解框架结构与项目上下文，Plugin Assets AI 处理资源侧，Flutter Skills 给 Agent 提供标准作业流程，GenUI 负责运行时动态生成界面，GenKit-Dart 则补齐服务端 AI 编排，Dart 由此可以同时承载客户端与后端。核心论点是：MCP Server 与 Agent Skills 的组合解决了「AI 对框架理解不准确」这一老问题——AI 不再靠训练语料里过时的 API 猜写法，而是从框架官方提供的能力描述里拿到当前版本的正确用法。对技术选型的意义在于，评价一个跨平台框架不能只看渲染性能，还要看它在 AI 工具链里的可编程程度。

### [实用性 Max，新 Flutter & Dart Agent Skills 深度解读](https://zhuanlan.zhihu.com/p/2035739970787394138)
**摘要**：解读 Flutter/Dart 官方 Agent Skills 的一次策略调整：从纯文档导向的 Skills 转为任务导向的 Skills，实用性显著提升。文章提出的关键观点是，好的 Skill 不应该只告诉 AI「某个 API 怎么用」，而要说清楚「什么场景下该选哪种方案、遇到问题怎么修、改完怎么验证」——即把资深工程师的判断路径而非 API 手册喂给模型。这对团队自建 Skills 有直接参考价值：文档型 Skill 在实际 Agent 工作流里容易变成检索噪音，任务型 Skill 才能真正减少来回返工。文章逐条拆解了官方新 Skills 的组织方式，可作为写内部 Skills 的模板参考。

### [Flutter GenUI 0.9 和 A2UI 0.9 发布，全动态 UI 支持，AI 在 App 里直出界面](https://zhuanlan.zhihu.com/p/2039013221722535584)

### [Flutter 发布官方 Skills，Flutter 在 AI 领域再添一助力](https://zhuanlan.zhihu.com/p/2012886441642975382)
