## Flutter

### [Flutter 3.44 更新要点：很重要但暂时先别升级](https://zhuanlan.zhihu.com/p/2043003077947569389)
**摘要**：这一版被文章定性为「结构性变更」而非常规迭代，三处改动值得单独盯：一是 Material 与 Cupertino 被移出 Flutter 框架核心，改为独立包管理；二是 Impeller 正式成为 Android 的默认渲染引擎；三是 iOS/macOS 构建侧 Swift Package Manager 取代 CocoaPods 成为默认配置，同时引入 Hybrid Composition++（HCPP），直接走 Vulkan 交换链来提升 Platform Views 的渲染表现。AI 侧的 Agentic Hot Reload 也从实验转为生产可用——AI 助手改完代码可自动触发热重载。作者的结论是：这种量级的发布不是「flutter upgrade 完继续干活」的情况，重度依赖 iOS/macOS 插件、Android platform views、自定义 Gradle、Flutter Web 或复杂 Material/Cupertino 包装层的项目，建议观望约两个月再动。
