## Flutter

### [Flutter 3.47 更新要点：Material 正式分家，老项目先别急着更新](https://zhuanlan.zhihu.com/p/2071985919243065015)
**摘要**：3.47 最大的变化是设计库正式拆包——Material 与 Cupertino 从 SDK 主体中独立出去，连 flutter_localizations 也被拆分，Material 与 Cupertino 的本地化 delegate 分别移入各自的包。这带来的直接后果是：混用 SDK 内置设计库与独立包会产生类型冲突和主题不一致，依赖第三方 UI 组件库的项目必须等上游先完成适配。文章给老项目的建议很明确——先别急着升，把依赖树盘一遍，确认所用组件库的适配进度后再统一切换。好处是长期的：拆包之后框架层的 UI 破坏性变更会显著减少，团队可以单独锁定样式包版本，不再被 SDK 的发版节奏绑架。
